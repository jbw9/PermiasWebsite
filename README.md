## Local Development
```bash
# Cloning and installing dependencies
git clone https://github.com/jbw9/PermiasWebsite.git
cd PermiasWebsite
npm install

# Supabase credentials (fill in the values)
cp .env.example .env

# Running the Server
npm start
```
